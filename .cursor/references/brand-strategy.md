# Brand Strategy — Codified Frameworks

## Kapferer's Brand Identity Prism

The foundational model for defining what a brand *is*. Six facets, two axes.

```
                    SENDER (Brand)
              ┌──────────┬──────────┐
              │ Physique  │Personality│
   EXTERNAL   ├──────────┼──────────┤   INTERNAL
              │Relationship│ Culture  │
              ├──────────┼──────────┤
              │Reflection │Self-Image│
              └──────────┴──────────┘
                   RECEIVER (Audience)
```

### Facet Definitions

| Facet | Question | Output Type |
|-------|----------|-------------|
| **Physique** | What does the brand look like? What are its physical specifics? | Visual identity, product design, color, shape language |
| **Personality** | If the brand were a person, who would they be? | Tone of voice, character traits, communication style |
| **Culture** | What values and principles drive the brand? | Mission, beliefs, origin story, philosophy |
| **Relationship** | What kind of relationship does the brand create? | Service model, community, transaction type |
| **Reflection** | Who is the brand's typical user (as perceived)? | Target archetype, aspirational identity |
| **Self-Image** | How does the user see themselves when using the brand? | Internal feeling, identity expression |

### How to Use

For every brand system, fill all six facets before any design work. Physique drives visual foundations. Personality drives verbal identity and motion. Culture drives messaging and narrative. All six must be internally consistent — contradiction between facets signals a brand that will feel incoherent.

## Wheeler's Five-Phase Process

The master workflow. Every brand project follows these phases with defined inputs and outputs.

### Phase 1: Conducting Research

**Inputs:** Stakeholder interviews, competitive audit, audience research, existing brand assets
**Activities:**
- Brand audit (inventory all existing touchpoints)
- Competitive analysis (map positioning landscape)
- Audience research (needs, perceptions, language)
- Stakeholder alignment (vision, values, ambitions)
**Outputs:** Research findings document, brand brief

### Phase 2: Clarifying Strategy

**Inputs:** Research findings
**Activities:**
- Define brand positioning (Neumeier's Onliness Statement)
- Complete Kapferer's Brand Identity Prism
- Establish brand architecture (Aaker's spectrum)
- Define brand personality (3–5 traits, ranked)
- Write brand narrative (Miller's SB7 if applicable)
**Outputs:** Brand strategy document, positioning statement, personality traits

### Phase 3: Designing Identity

**Inputs:** Brand strategy document
**Activities:**
- Explore visual directions (color, typography, shape)
- Develop verbal identity (voice, tone, naming conventions)
- Design logo/wordmark (if applicable)
- Create initial motion explorations
**Outputs:** Visual identity concepts, verbal identity framework

### Phase 4: Creating Touchpoints

**Inputs:** Approved identity direction
**Activities:**
- Apply identity across all touchpoints (digital, print, environmental)
- Build component library and pattern system
- Create content templates
- Develop motion library
**Outputs:** Touchpoint designs, asset library, template system

### Phase 5: Managing Assets

**Inputs:** Complete identity system
**Activities:**
- Create brand guidelines document
- Build design token system (W3C DTCG)
- Establish governance and approval workflows
- Train teams on brand application
**Outputs:** Brand guidelines, design tokens, governance model

## Neumeier's Onliness Statement

A fill-in-the-blank positioning template that forces clarity:

```
Our [BRAND] is the only [CATEGORY] that [DIFFERENTIATOR].
```

### Extended Version
```
What:   The only [category]
How:    That [differentiator]
Who:    For [target audience]
Where:  In [market/geography]
Why:    Who [need/desire]
When:   During [trend/moment]
```

### Evaluation Rules
- If competitors can claim the same statement, it's not distinctive enough
- If the audience doesn't care about the differentiator, it's not relevant enough
- If you can't deliver the differentiator, it's not authentic enough

## Aaker's Brand Architecture

### Brand Relationship Spectrum

A continuum for how brands relate within a portfolio:

```
BRANDED HOUSE ←────────────────────────────→ HOUSE OF BRANDS

  Google          Apple          P&G           Unilever
  (master brand   (master with   (endorsed     (independent
   dominates)      sub-brands)    brands)       brands)
```

| Model | Description | When to Use |
|-------|-------------|-------------|
| **Branded House** | Single master brand across all products (Google, FedEx, Virgin) | Strong master brand, related offerings, efficiency |
| **Sub-brands** | Master brand + descriptive sub-brand (Apple iPhone, Microsoft Office) | Extensions that need own identity but benefit from parent |
| **Endorsed Brands** | Independent brands with parent endorsement (Courtyard by Marriott) | New brands needing credibility, different audiences |
| **House of Brands** | Independent brands, parent hidden (P&G → Tide, Pampers, Gillette) | Distinct audiences, category conflicts, M&A |

### Architecture Decision Criteria

Choose based on:
1. **Leverage** — Does the parent brand add value?
2. **Clarity** — Will the audience understand the relationship?
3. **Synergy** — Do the brands reinforce each other?
4. **Risk** — Does one brand's failure damage others?

## Romaniuk's Distinctive Brand Assets

### The Fame × Uniqueness Grid

Every brand asset is scored on two dimensions:

```
           High Fame (known)
                ↑
    AVOID USE   │   USE OR LOSE
    (famous but │   (famous AND
     not unique)│    unique = ideal)
    ────────────┼────────────────→ High Uniqueness
    IGNORE      │   INVEST/TEST
    (neither    │   (unique but
     known nor  │    not yet famous)
     unique)    │
```

| Quadrant | Strategy |
|----------|----------|
| **Use or Lose** (high fame + high uniqueness) | Protect and deploy consistently. These are crown jewels. |
| **Invest/Test** (low fame + high uniqueness) | Increase exposure. These have potential. |
| **Avoid Use** (high fame + low uniqueness) | Dangerous — associated with category, not your brand. |
| **Ignore** (low fame + low uniqueness) | Not worth investment. Replace or drop. |

### Asset Types to Evaluate

- Colors (brand color)
- Shapes (logo shape, product shape)
- Taglines/slogans
- Characters/mascots
- Celebrities/spokespeople
- Typography
- Sounds/jingles
- Patterns/textures
- Tone of voice

## Miller's StoryBrand SB7 Framework

Structure brand messaging as a story where the *customer* is the hero:

```
1. CHARACTER    → The customer wants something
2. PROBLEM      → They face a problem (external, internal, philosophical)
3. GUIDE        → They meet a guide (your brand) who has empathy + authority
4. PLAN         → The guide gives them a plan (3–4 steps)
5. CALL TO ACTION → The guide calls them to action (direct + transitional)
6. FAILURE      → Helping them avoid failure (stakes)
7. SUCCESS      → And achieve success (transformation)
```

### Three Levels of Problem
- **External** — The tangible, surface-level problem
- **Internal** — How the problem makes them feel
- **Philosophical** — Why this problem is fundamentally wrong

### BrandScript Template
```
[CUSTOMER] wants [DESIRE].
The problem is [EXTERNAL PROBLEM], which makes them feel [INTERNAL PROBLEM].
This is wrong because [PHILOSOPHICAL PROBLEM].
[BRAND] understands [EMPATHY STATEMENT] and has [AUTHORITY].
Here's the plan: Step 1 [___], Step 2 [___], Step 3 [___].
[DIRECT CTA] or start with [TRANSITIONAL CTA].
If they don't act, they risk [FAILURE/STAKES].
When they do, they experience [SUCCESS/TRANSFORMATION].
```

## Johnson's Six Strategic Questions

Before any design work, answer:

1. **What are we actually doing?** (Core purpose — one sentence)
2. **What makes us different?** (Unique value proposition)
3. **Who are we talking to?** (Primary audience — be specific)
4. **What do we want them to think?** (Desired perception — one sentence)
5. **What do we want them to feel?** (Emotional response — one word)
6. **What do we want them to do?** (Desired action — one verb)

The "half step": design discoveries feed back into strategy. This is iterative, not linear.

## Brand Audit Checklist

When evaluating an existing brand, inventory:

### Touchpoint Inventory
- [ ] Logo (primary, secondary, icon, wordmark)
- [ ] Color palette (primary, secondary, accent, neutrals)
- [ ] Typography (headings, body, display, code)
- [ ] Photography/illustration style
- [ ] Iconography
- [ ] Motion/animation style
- [ ] Sound/audio identity
- [ ] Voice and tone
- [ ] Naming conventions
- [ ] Key messaging/taglines
- [ ] Business cards, letterhead
- [ ] Website, app, digital products
- [ ] Social media presence
- [ ] Email templates
- [ ] Packaging (if applicable)
- [ ] Environmental/signage (if applicable)
- [ ] Advertising templates
- [ ] Presentation templates
- [ ] Documentation style

### Consistency Assessment
For each touchpoint, score 1–5:
- Does it express the brand personality consistently?
- Does it use brand colors correctly?
- Does it use brand typography correctly?
- Does it follow the voice and tone guidelines?
- Does it feel like it belongs to the same brand as all other touchpoints?
